# 小数据格式与模型组合测试

这里的 27 份数据均为固定随机种子生成的合成数据，每份只有 48 行。`binary` 是二分类，`multiclass` 是三分类，`regression` 是连续结局；每种数据都有 CSV、TSV、XLSX、XLS、SAV、DTA、XPT、Parquet、SAS7BDAT 九个版本。同一任务各格式的数据含义相同。

在应用中选择“导入配置”，打开对应的 `*_config.json` 即可恢复数据路径、变量和快速分析设置。也可以直接导入数据后自行选择模型。默认配置使用两折分组验证、深度为 3 的决策树，不搜索参数、不生成图片，便于快速检查。

- 特征：`signal`、`noise`、`category`，包括数值和分类变量。
- 目标：`target`；分组：`participant`，8 组，每组 6 行。
- `signal` 和 `category` 各有 2 个缺失值。选择删除缺失行时，九种格式都应保留 44 行。
- `admin_note` 全为空，是刻意设置的未选中列，不应影响所选特征的行数。
- 分类变量会带来共线的独热编码。混合特征使用 QDA 时需要研究者明确选择适当的正则化参数，例如本测试采用 `reg_param=0.1`；未经正则化的 QDA 不适合这份混合数据。程序不会悄悄更改参数。

`manifest.json` 列出前八种格式；`sas7bdat_manifest.json` 列出三份实际 SAS7BDAT 二进制文件、配置、大小、校验值和写入器来源。每份 SAS7BDAT 为 16 KB，已用 pyreadstat 与 pandas 两个独立读取器核对原始数据，并测试 GUI 配置导入、分析导出、命令行调参和损坏文件报错。

SAS7BDAT 样例由 ReadStat 写入器生成，不是 SAS 软件生成。[ReadStat 上游说明](https://github.com/WizardMac/ReadStat#readstat-read-and-write-data-sets-from-sas-stata-and-spss)指出其输出存在 SAS 软件兼容性限制；这些真实二进制样例用于验证本项目的导入分析能力，不能代表已通过 SAS 软件验收或覆盖所有 SAS 版本、压缩方式、目录标签。

## 开发者快速复测

在仓库根目录执行：

```bash
uv sync --locked --group dev
uv run pytest tests/test_parameter_matrix.py -q --durations=10
```

这组测试包含 805 项，当前本机约一分钟完成；持续集成的默认 `pytest` 也会自动运行它们。测试失败会显示任务、模型和组合编号，便于只重跑该项。

| 层次 | 数量 | 检查内容 |
| --- | ---: | --- |
| 所有模型 × 缺失处理 × 缩放 | 276 | 23 个任务/模型组合，4 种缺失处理，3 种缩放；实际训练并预测未见分类值 |
| 推荐参数网格 | 193 | 逐个拟合全部推荐候选，分类分别测试二分类和三分类；不缩减推荐值 |
| 所有模型 × 适用验证方法 | 116 | 分类 6 种、回归 4 种；实际预测、指标、导出文件和失败状态 |
| 文件读取、配置导入与分析 | 27 | 九种格式 × 三种任务数据，数值往返、缺失行、GUI 配置解析和结果导出 |
| SAS7BDAT 独立读取核对 | 3 | pandas 独立解析、逐列数值与缺失值比较、文件校验值 |
| SAS7BDAT 命令行调参与导出 | 3 | 二/三分类、回归；删除缺失值后 44 行；两个候选、进度与成功事件 |
| 损坏 SAS7BDAT | 1 | 截断真实二进制文件，错误必须包含格式与文件名 |
| 所有模型 × 两种调参模式 | 46 | quick/custom，内层选择和最终重拟合，候选上限为 2 |
| 堆叠方法交互 | 8 | auto/predict × 是否传递原始特征 × 二/三分类 |
| 不兼容参数 | 10 | 错误必须有原因，不能写出成功结果标记 |
| 失败候选与成功候选共存 | 12 | 六种选择指标 × 两种验证；失败候选不得阻断有效候选 |
| 数据类型与缺失边界 | 60 | 可空布尔、可空数值、全分类特征、中文标签、整列缺失 × 12 种预处理 |
| 额外自定义参数交互 | 50 | 核函数、概率输出、邻居算法、距离、LDA 收缩、树的比例参数、MLP 求解器/早停等 |

为控制运行时间，除“全部推荐候选”测试外，部分测试明确使用 5 棵树、小型神经网络或两折堆叠。推荐网格中的无正则化 QDA 在非共线数值特征上测试；其混合特征失败情形单独验证。测试检查可运行性、输出完整性及失败处理，不以预测分数高低作为通过条件。

全部参数的笛卡尔积和任意真实数据无法穷举；该矩阵覆盖完整推荐网格、主要两两组合及具体高风险交互，不代表对所有未测组合的保证。训练警告仍会保留，例如迭代未收敛、整列缺失被跳过、依赖参数弃用。矩阵中有限迭代的收敛警告只在相应测试显示层被过滤，产品行为没有改变。

需要重新生成或换位置：

```bash
uv run python tools/generate_matrix_data.py --output-dir examples/synthetic/matrix
uv run python tools/generate_sas_data.py --output-dir examples/synthetic/matrix
```

生成器只写入给定目录下的固定合成文件名；重新生成会覆盖这些同名夹具和配置。CLI 读取相对数据路径时以当前工作目录为准，因此使用这些便携配置运行 CLI 应先切换到本目录；GUI 导入会自动以配置目录解析数据路径。分析结果目录必须是新的空目录。

SAS 生成工具使用锁定 pyreadstat 中的 ReadStat C 接口，只用于维护夹具，不进入产品运行路径。若平台未导出这些符号，可用 `--readstat-library` 指定独立 ReadStat 动态库。正常自动测试直接读取仓库中的 SAS 二进制文件，不调用该私有写入接口，也不需要安装 SAS。只复测文件格式与 SAS 补测约需几秒：

```bash
uv run pytest tests/test_parameter_matrix.py -q -k "sas7bdat or each_format_roundtrip"
```
