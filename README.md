# PsyML Toolkit

## Background

PsyML Toolkit originated from Python machine-learning scripts developed during undergraduate research and applied projects. This repository currently preserves those legacy assets while their structure, reproducibility, and statistical methods are assessed.

## Current capabilities

### Regression

- KNN regression
- Lasso regression
- MLP regression
- Random Forest regression
- Support Vector Regression

### Classification

- KNN classification
- Random Forest classification
- Stacking classification
- Support Vector Machine classification
- MLP classification
- Decision Tree classification

### Experimental

- RNN-based NLP classification

## Status

Legacy preservation and modernization in progress. The repository remains private while data ownership and publication permissions are verified.
