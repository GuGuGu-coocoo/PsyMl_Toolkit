# GUI 人工测试指南

适用于本次审查后的 PsyML Toolkit（2026-09-05）。测试数据全部为随机/规则合成数据，不代表任何真实研究。先完成约 15 分钟的主流程，再按需完成 15–20 分钟的边界测试。首次安装依赖的时间不计入这两个时段。

## 准备与共同记录

在项目根目录启动（本机现有环境已验证）：

```bash
cd /Users/gugu/workspace/00_projects/02_PsyMl_Toolkit
.venv/bin/python tools/launch_gui.py
```

新环境按 README 安装后可用 `uv run python tools/launch_gui.py`。需要 Godot 4.7.2；不在 PATH 时设置 `PSYML_GODOT` 为其可执行文件路径。启动的是项目 GUI，不是打开 Godot 编辑器。

测试文件已提供，无需联网或手工造表：

- [classification.csv](../examples/synthetic/classification.csv)：48 行、5 列、12 组、二分类。
- [regression.csv](../examples/synthetic/regression.csv)：48 行、5 列、12 组、连续目标。
- [two_groups.csv](../examples/synthetic/two_groups.csv)：8 行、2 组，供错误测试。

五列为 `score`、`category`、`participant`、`target`、`admin_note`。`admin_note` 全部缺失，故意用于检验未选管理字段是否影响样本；它不得进入本测试的预测变量。生成规则位于 `tools/generate_gui_test_data.py`，种子为 20260905。分析种子在 GUI 中固定为 42，留出比例固定为 0.2；这两项可在配置中核对，GUI 没有可编辑的种子/比例控件。

每次运行用一个新路径，例如 `/tmp/PsyML-manual/class-01`、`reg-01`、`stop-01`、`error-01`、`retry-01`。父目录可以相同，最终结果目录必须不存在或为空。不要删除已有输出来重试。

每步失败时至少记录：步骤编号、操作时间、语言、窗口尺寸、界面截图、状态/错误原文、使用的合成文件、所选变量/验证/模型/参数及结果目录。有输出时保留 `config.json`、`warnings.json`、`model_comparison.csv`；没有时复制“检查与运行”的配置文字。只反馈合成测试材料。

**实际操作提示：**页签依次是“1 数据与变量”“2 分析设置”“3 检查与运行”“4 结果”。文件按钮叫“浏览…”，不是“选择文件”。选文件后会自动预览并进入分析设置；直接编辑路径时点击“读取预览”。变量、模型和验证使用多选列表，不是勾选框。普通点击可单选；按住 Command（macOS）/Ctrl（Windows、Linux）点击以增减选择，Shift 可选连续项；以高亮项及配置数组为准。列表和页面可能各有独立滚动条；参数区在分析设置页面下方。

## 结果解释与已知边界

- 主要指标、验证目标、真实研究排除规则和正类含义由研究者预先决定。本指南的设置只服务于软件验收。
- 当前比较用主要验证的外层成绩选择模型家族。获胜成绩不是经过家族选择后的独立无偏性能估计；嵌套参数搜索不自动解决家族选择偏差。
- 折均值不按样本数/组大小加权，标准差不是置信区间；undefined 次要指标可能只汇总部分折，应看 n_folds。缺类别折会提示且不报告不适用的 AUC。不能凭一个高分忽略这些提示。
- 二分类 AUC 的正类为模型 classes_[1]，不是 GUI 可指定的临床正类；预测 CSV 目前不导出概率列。混淆矩阵图用 Class 1/2 等匿名标签，其顺序对应 confusion_matrix.csv。
- GUI 仅预览比较表前30条、预测前20条；完整结果看 CSV。模型对象仅由 Python API 返回，GUI 不导出可加载的已拟合模型文件。
- 本轮在 macOS / Godot 4.7.2 实际运行。Windows/Linux 的文件对话框、系统缩放与键盘修饰键仍需当地人工核查。读取源文件期间外部修改文件、多进程同时向同一空目录运行，以及强制关机期间的文件状态未实测。
