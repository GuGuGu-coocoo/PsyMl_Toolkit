# PsyML Toolkit v0.3.0

## 中文

本版把四项新分析能力和一组界面与流程改进合并为正式版本 0.3.0：置换重要性、数据检查与结果解读、单样本 SHAP 解释和拟合系数；同时统一版本标识、结果目录、第 4 页“只打开、不导出”的产物流程。界面与说明仍提供中文、英文和法文。

- **下载**：`PsyML-Toolkit-0.3.0-Windows-x64.zip` 与 `PsyML-Toolkit-0.3.0-macOS-arm64.zip` 从同一提交构建；实际可下载的附件与平台以 [v0.3.0 Release](https://github.com/GuGuGu-coocoo/PsyMl_Toolkit/releases/tag/v0.3.0) 页面为准（更早版本仍见 [Releases](https://github.com/GuGuGu-coocoo/PsyMl_Toolkit/releases)）。两种应用都包含运行环境，无需安装 Python 或使用命令行。
- **置换重要性**：默认关闭；在结果中按验证输出变量置换重要性的原始/折间/汇总 CSV、JSON 与图，重复次数可设置。只在对应外层测试数据上解释内层选出的折模型，保留负值，重复置换波动与跨折波动分开报告；不参与模型选择，也不改变划分或评价。
- **数据检查与结果解读**：第 1 页按列给出非缺失数、唯一数、类别数量与占比、疑似编号信号，均以已观测值为分母，不自动删列；结果页把成功运行的指标与同验证、同折集合、同指标的 Dummy 基线比较，方向固定（正=更好），无基线或折集合不同时明确标注不可比较，单折不判断稳定性。
- **单样本 SHAP 解释（可选 explain 依赖）**：对选定的一个样本给出基准值、逐变量贡献与累计瀑布图，并用 `base + Σφ = 所选输出` 做重建核验；背景行数量与代价、类别轴、近似性质与限制都在结果中写明。
- **拟合系数**：对适用模型给出截距、变换后特征单位上的系数、来源列与类别映射，并用同一 Pipeline 重建 `predict`/`decision_function` 核验；核验失败时拒绝写出成功产物，无样本时明确标注未核验。
- **界面与流程改进**：软件名下方显示单一来源的版本小字；滚轮/滑动手势的控制层由起手位置锁定；训练结果写入 `training/run_*`，第 4 页预测、SHAP、系数分别写入共享根目录下 `prediction/`、`explanation/`、`coefficients/` 的 `run_*`，旧版直接放在根目录的 `run_*` 仍可原位打开；预测产物为可直接打开的 `predictions.csv`；第 4 页三块只有“打开结果文件夹/打开瀑布图”，没有复制或另存导出入口；收尾写入阶段显示“正在整理并写出结果…”且进度条未满；三语指南与术语表同步。
- **版本与构建**：版本只有一个维护来源（`src/psyml/__init__.py` 的 `__version__`），独立包 `BUILD.json` 与界面显示同一值；原生导出统一走 `tools/build_native.py`。

**科学限制**：置换重要性是逐行边际置换的近似，分组数据不保持受试者内依赖；单样本 SHAP 是有限背景下的近似贡献，背景替换不保持变量间相关结构，二者都不是因果解释或外层性能估计。系数只描述该次拟合在变换后特征单位上的关系，不换算回原始单位，也不含显著性推断；分类 logistic 系数为 log-odds、线性 SVC 为 margin，多类为 softmax logit。数据检查与结果解读只汇总本次运行已有的证据，不代替研究设计。新数据预测与内部验证分数都不构成独立外部验证。合成样例仅用于熟悉软件。应用未商业签名/公证，首次启动可能需要按系统提示确认。

## English

This release folds four new analysis capabilities and a set of interface and flow improvements into the official 0.3.0 version: permutation importance, data checks and result interpretation, single-sample SHAP explanations and fitted coefficients, together with a single version label, unified output folders and an open-only page 4 artifact flow. The interface and these notes remain available in Chinese, English and French.

- **Download:** `PsyML-Toolkit-0.3.0-Windows-x64.zip` and `PsyML-Toolkit-0.3.0-macOS-arm64.zip` are built from the same commit; the assets and platforms actually available are those listed on the [v0.3.0 Release](https://github.com/GuGuGu-coocoo/PsyMl_Toolkit/releases/tag/v0.3.0) page (earlier versions remain under [Releases](https://github.com/GuGuGu-coocoo/PsyMl_Toolkit/releases)). Both applications include the runtime; no Python installation or terminal is needed.
- **Permutation importance:** off by default; results contain raw/per-fold/summary CSVs, a JSON document and a figure per validation, with a configurable repeat count. Only the inner-selected fold model is explained on its outer test rows; negative values are kept, and repeat-to-repeat variability is reported separately from across-fold variability. It never feeds back into selection, splitting or scoring.
- **Data checks and result interpretation:** page 1 reports per-column non-missing counts, unique counts, category counts and shares, and evidence-based identifier hints, all with observed values as the denominator and without deleting columns; the result page compares a successful run against a dummy on the same validation, folds and metric with a fixed sign (positive = better), states an explicit not-comparable reason otherwise, and makes no stability claim for a single fold.
- **Single-sample SHAP explanation (optional explain extra):** for one selected row it reports the base value, per-variable contributions and a cumulative waterfall, and verifies reconstruction with `base + Σφ = selected output`; background size and cost, the output axis, and the approximation and its limits are documented in the results.
- **Fitted coefficients:** for supported models it reports the intercept, coefficients in transformed-feature units, source columns and category mappings, and verifies `predict`/`decision_function` reconstruction through the same pipeline; a failed check refuses to publish a success artifact, and missing rows are explicitly unverified.
- **Interface and flow improvements:** a single-source version label under the application name; wheel/swipe scroll ownership locked to the gesture start; training runs under `training/run_*` while page-4 prediction, SHAP and coefficients land in `run_*` folders under `prediction/`, `explanation/` and `coefficients/` in the shared root, with legacy root-level `run_*` folders still opening in place; prediction output is a directly openable `predictions.csv`; the three page-4 blocks only offer open actions, with no copy or save-as entry; final result writing shows a dedicated status with the bar not full; the trilingual guides and terminology are synchronised.
- **Version and build:** one maintained version source (`__version__` in `src/psyml/__init__.py`), shared by the standalone `BUILD.json` and the interface label; native export goes through `tools/build_native.py` only.

**Scientific limits:** permutation importance is a row-wise marginal approximation and does not preserve within-subject dependence in grouped data; single-sample SHAP is an approximate contribution under a finite background, and background replacement does not preserve correlation structure; neither is a causal explanation or an outer-performance estimate. Coefficients describe this fit in transformed-feature units, are not converted to raw units, and contain no significance inference; classification logistic coefficients are log-odds, linear SVC coefficients are margins and multi-class logistic coefficients are softmax logits. Data checks and result interpretation only summarise evidence already computed for this run and do not replace study design. Prediction and internal validation scores are not independent external validation. Synthetic examples only exercise the software. Applications are not commercially signed/notarized; follow the OS first-launch prompts.

## Français

Cette version réunit quatre nouvelles capacités d’analyse et une série d’améliorations d’interface et de flux dans la version officielle 0.3.0 : importance par permutation, contrôle des données et interprétation des résultats, explication SHAP d’un échantillon et coefficients ajustés, avec une étiquette de version unique, des dossiers de sortie unifiés et un flux page 4 limité à l’ouverture. Interface et notes restent disponibles en chinois, anglais et français.

- **Téléchargement :** `PsyML-Toolkit-0.3.0-Windows-x64.zip` et `PsyML-Toolkit-0.3.0-macOS-arm64.zip` sont construits depuis le même commit ; les fichiers et plateformes réellement disponibles sont ceux listés sur la page [Release v0.3.0](https://github.com/GuGuGu-coocoo/PsyMl_Toolkit/releases/tag/v0.3.0) (les versions antérieures restent sous [Releases](https://github.com/GuGuGu-coocoo/PsyMl_Toolkit/releases)). Les deux applications incluent leur environnement ; aucune installation Python ni terminal nécessaire.
- **Importance par permutation :** désactivée par défaut ; les résultats contiennent par validation les CSV brut/par pli/récapitulatif, un JSON et une figure, avec un nombre de répétitions réglable. Seul le modèle de pli choisi en interne est expliqué sur ses lignes de test externes ; les valeurs négatives sont conservées et la variabilité entre répétitions est distinguée de celle entre plis. Elle ne revient jamais dans la sélection, le découpage ou le score.
- **Contrôle des données et interprétation :** la page 1 indique par colonne les valeurs non manquantes, les valeurs uniques, les effectifs et parts des catégories et des indices d’identifiant justifiés, avec les valeurs observées comme dénominateur et sans supprimer de colonne ; la page de résultats compare une exécution réussie à un dummy sur la même validation, les mêmes plis et la même métrique, avec un sens fixe (positif = meilleur), une raison explicite de non-comparabilité sinon, et aucune affirmation de stabilité sur un seul pli.
- **Explication SHAP d’un échantillon (extension explain facultative) :** pour une ligne choisie, valeur de base, contributions par variable et cascade cumulative, avec vérification `base + Σφ = sortie choisie` ; taille et coût du fond, axe de sortie, approximation et limites sont documentés dans les résultats.
- **Coefficients ajustés :** pour les modèles compatibles, intercept, coefficients en unités de variables transformées, colonnes sources et correspondances de catégories, avec vérification de la reconstruction de `predict`/`decision_function` par le même pipeline ; un échec refuse de publier un artefact de succès et l’absence de lignes reste explicitement non vérifiée.
- **Améliorations d’interface et de flux :** étiquette de version à source unique sous le nom de l’application ; propriété du défilement molette/balayage verrouillée au départ du geste ; entraînement sous `training/run_*` et sorties page 4 dans des dossiers `run_*` sous `prediction/`, `explanation/` et `coefficients/` dans la racine partagée, les anciens dossiers `run_*` à la racine s’ouvrant toujours en place ; sortie de prédiction `predictions.csv` directement ouvrable ; les trois blocs de la page 4 n’offrent que l’ouverture, sans copie ni export ; l’écriture finale affiche un état dédié avec une barre non pleine ; guides et terminologie trilingues synchronisés.
- **Version et construction :** une seule source de version (`__version__` dans `src/psyml/__init__.py`), partagée par le `BUILD.json` autonome et l’étiquette de l’interface ; l’export natif passe uniquement par `tools/build_native.py`.

**Limites scientifiques :** l’importance par permutation est une approximation marginale ligne à ligne et ne préserve pas la dépendance intra-sujet des données groupées ; le SHAP d’un échantillon est une contribution approchée sous un fond fini, et le remplacement du fond ne préserve pas la structure de corrélation ; ni l’un ni l’autre n’est une explication causale ou une estimation de performance externe. Les coefficients décrivent cet ajustement en unités de variables transformées, sans conversion vers les unités brutes ni inférence de significativité ; les coefficients logistiques de classification sont des log-odds, ceux d’un SVC linéaire des marges et ceux d’une logistique multiclasse des logits softmax. Le contrôle des données et l’interprétation ne résument que les preuves déjà calculées pour cette exécution et ne remplacent pas le plan d’étude. Prédiction et scores de validation interne ne constituent pas une validation externe indépendante. Les exemples synthétiques servent uniquement à la prise en main. Applications sans signature commerciale ni notarisation ; suivez les indications du système au premier lancement.
