# 模型家族选择与独立验证：依据、决定和实施

2026-09-05。第一轮修复已提交并推送为 `d4b139c`。随后用户明确选择“采用完整嵌套选择”，本记录描述该决定后的实现，取代第一轮报告中“主要外层成绩选择家族”的当前状态描述。

## 结论与研究依据

没有适合所有研究的单一最优切分。针对本工具的多模型选择，合理的内部修正是把**家族和超参数作为同一个内层选择问题**，外层评价完整选择流程。仅在每个家族内部调参，然后用这些家族的外层最高分选家族并报最高分，仍会对评价准则过拟合。[Cawley & Talbot, JMLR 2010](https://www.jmlr.org/papers/v11/cawley10a.html)

嵌套验证所评价的是学习与选择程序，不是“最终用全数据拟合的这个模型已经在独立数据上获得同样表现”。外层训练样本较少，切分也带来变异；不能将嵌套结果宣传为消除了所有偏差或证明了临床/实际用途。[scikit-learn 官方嵌套验证示例](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)

跨中心、时间或人群的外推仍需匹配使用场景的数据。独立评价的数据不应进入模型开发、调参或选择；重复测量要按研究中的独立单位处理。把同一文件再导入 GUI 并重新训练，不是独立验证。[TRIPOD+AI, BMJ 2024](https://www.bmj.com/content/385/bmj-2023-078378)，[scikit-learn 分组验证](https://scikit-learn.org/stable/modules/cross_validation.html)

## 选项及本次决定

| 方案 | 回答什么问题 | 代价与边界 | 本版 |
|---|---|---|---|
| 预先指定单一家族 | 该预定家族/参数选择程序在当前外层设计中的表现 | 不能先看排行榜再声称预先指定 | 保留支持 |
| 完整嵌套家族＋参数选择 | 预先规定的候选集合、指标、预处理与选择程序的内部泛化表现 | 计算增加；每个外层训练集还必须能完成内层验证；逐折可选不同家族 | **用户选择并实施** |
| 锁定模型后评估独立数据 | 已锁定模型在目标场景的新数据表现 | 需要独立数据、冻结的处理和模型、预定评价计划；一次随机留出不等于跨场景外部验证 | 本 GUI 尚无冻结模型加载与独立数据评分流程，不伪装为已有功能 |

本次没有更改主要指标、缺失目标删除规则、折权重、正类约定或分组含义。它们仍由研究设计决定。主要验证依旧是 GUI 固定列表中最靠前的已选项，点击先后不是优先级。

## 现在实际执行什么

1. 在所选外层训练分区内，按共同的内层切分评价所有候选家族及其参数。编码、填补、缩放属于候选流水线，只拟合当前训练折。有分组列时内层隔离组。
2. 按既定指标方向选择内层平均分最佳的家族/参数。相等时保留配置中的家族与候选顺序。**关闭参数搜索也不关闭多家族的内层选择。**
3. 外层测试只评价该折内层已选定的模型。各家族的额外外层成绩留在探索性排行榜中，不用于决定该折选择、最终家族或参数。
4. 主指标、主图与主预测组合主要验证下逐折选中的模型；预测新增 `model` 列。单家族分析仍评价该家族的外层表现。
5. 在全部分析数据上重新用内层验证选择最终家族和参数，再拟合全数据。主图/主指标不因此改成全数据训练成绩。
6. 所有候选内部折必须得到有限的主要分数；候选内部折失败则该候选不入选。若内层选中的模型外层失败，该验证的选择流程失败，不能根据外层表现换一个家族。主要验证失败终止整个分析；敏感性流程失败在摘要中明确标出，不冒充完整评价。

## 可复核输出

| 文件/字段 | 含义 |
|---|---|
| `selection_protocol=nested_family_v1` | 配置与摘要显式记录本次选择协议；不提供旧外层选家族模式的隐式回退 |
| `result.json:evaluation_scope` | 多家族为 `nested_selection_procedure`，单家族为 `prespecified_family` |
| `selection_trace.csv` | 每个外层折及最终全数据选择的家族、参数、内部得分；`score` 是内层选择指标，绝非新的独立性能成绩；`outer_fold=0` 为最终选择 |
| `parameter_search.csv` | 全部家族的内部候选证据，包括最终全数据的家族比较；固定单候选单家族没有必要的搜索行 |
| `validation_summary.csv` | 各验证的完整流程成绩、primary/sensitivity、成功/失败及有效外层折数 |
| `model_comparison.csv` | 探索性单家族的外层排行榜；第一名可能不是最终家族，不能把其获胜成绩冒充主评价 |
| `predictions.csv` / `fold_metrics.csv` | 主要验证下所选流程的样本外预测与逐折成绩；模型可以逐折不同 |
| `best_parameters.json` | 最终全数据内层选择的参数覆盖；完整默认值仍须结合所记录的软件版本解释 |

旧版配置缺少新字段时，读入后明确采用新协议并在输出补齐字段；不是旧版数值复现模式。重跑历史研究需保留原版本与环境，不能只用旧配置搭配新代码声称数值一致。

## 直接修复证据

[回归测试](../../tests/test_nested_family_selection.py) 包含：

- 人为使 Dummy 外层排行榜第一，但真实内层选择树模型；最终家族与逐折预测仍来自树，主指标也不被替换成榜首分数。
- 只翻转外层留出标签，该折内层的家族、参数与内部得分保持不变，外层准确率从 1 降至 0。
- 内层选中模型外层失败、Dummy 外层成功时，主要验证必须失败且无 `result.json`，不能切换到 Dummy。
- 关闭参数搜索时仍实测两家族内部评价；每个内层和外层切分的组集合不相交；最终内层比较包含两个家族。
- 加入敏感性策略不改变主要预测或最终家族/参数；只有一个可用内部组时明确失败。

这些测试验证信息边界和错误行为，不是用合成数据高分证明科学效度。实际 Computer Use 范围与结果另见 [验收记录](CUA_ACCEPTANCE.md)。

## 公开第一版的适用范围

可以将本版描述为“本地表格数据的模型开发、内部嵌套评价与探索性比较工具”。不得将主分数描述为最终模型的独立外部验证成绩，也不得承诺自动完成研究设计、诊断效能验证或部署决策。

研究者仍需预定目标、独立单位、评价指标及排除规则；数值型类别编码目前按 dtype 处理，应在导入前正确表达类别。当前没有时间序列切分、正类/阈值编辑、概率导出与校准评价、推断性置信区间、独立冻结模型评分。单次极小样本的成功运行不能解决这些研究要求。重复检查结果后调整候选/数据/规则也会产生新的选择偏差。
